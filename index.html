Humancha

Humancha (portmanteau of Human and CAPTCHA) is a CAPTCHA API based on the Decoy Font by Mixfont.
It requires no Docker, no backend, and it is free and simple to use.

Overview

Humancha provides CAPTCHA challenges as WebP images. Retrieve a challenge with JavaScript and submit the user's answer for server-side verification.

GET /api/captcha

Creates a challenge. The response body contains the WebP image. Session information is returned through response headers. 

Content-Type: image/webp
X-Captcha-Session: session-id
X-Captcha-Hash: signed-challenge-token
X-Captcha-Expires: unix-timestamp

Display the image

You can display a challenge using a regular img element. 

<img
  src="https://YOUR-API-DOMAIN/api/captcha"
  alt="CAPTCHA"
>

An image element cannot read the session and challenge headers. Use JavaScript fetch when verification is required.

POST /api/captcha/verify

Submit the session ID, challenge hash, and user's answer as JSON. 

{
  "session_id": "session-id",
  "captcha_hash": "signed-challenge-token",
  "answer": "user-answer"
}

Successful verification returns valid: true. Incorrect attempts are tracked per session.

POST /api/captcha/refresh

Send the current session ID and challenge hash. The response contains a new WebP image and new session headers. 

{
  "session_id": "session-id",
  "captcha_hash": "signed-challenge-token"
}

Challenge behavior

Challenges expire after their configured lifetime. Verification is performed server-side. Incorrect attempts are tracked, and refreshed challenges receive new sessions.

Code examples

Get started with Humancha using your preferred language. Replace the example values with your challenge details. 

curl -sS -D captcha-headers.txt -o captcha.webp https://humancha.l.cd/api/captcha

# Read the session ID and hash from captcha-headers.txt.
grep -iE 'X-Captcha-(Session|Hash):' captcha-headers.txt

# Replace the placeholders with the returned values.
curl -sS -X POST https://humancha.l.cd/api/captcha/verify \
  -H 'Content-Type: application/json' \
  -d '{"session_id":"SESSION_ID","captcha_hash":"CAPTCHA_HASH","answer":"YOUR_ANSWER"}'
const API = "https://humancha.l.cd";

let sessionId;
let captchaHash;
let imageUrl;

const image = document.querySelector("#captcha-image");
const answer = document.querySelector("#answer");

async function loadCaptcha() {
    const response = await fetch(`${API}/api/captcha`, {
        cache: "no-store"
    });

    if (!response.ok) {
        throw new Error("Could not create CAPTCHA.");
    }

    sessionId = response.headers.get("X-Captcha-Session");
    captchaHash = response.headers.get("X-Captcha-Hash");

    if (!sessionId || !captchaHash) {
        throw new Error("Missing CAPTCHA headers.");
    }

    if (imageUrl) {
        URL.revokeObjectURL(imageUrl);
    }

    imageUrl = URL.createObjectURL(await response.blob());
    image.src = imageUrl;
}

async function verifyCaptcha() {
    const response = await fetch(`${API}/api/captcha/verify`, {
        method: "POST",
        headers: {
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            session_id: sessionId,
            captcha_hash: captchaHash,
            answer: answer.value
        })
    });

    const result = await response.json();

    if (!response.ok) {
        throw new Error(result.detail || "Verification failed.");
    }

    return result;
}

// Load a challenge.
loadCaptcha().catch(console.error);

// Call verifyCaptcha() when the user submits their answer.
import requests

API = "https://humancha.l.cd"

with requests.Session() as client:

    # Create a challenge.
    response = client.get(
        f"{API}/api/captcha",
        timeout=15
    )
    response.raise_for_status()

    session_id = response.headers["X-Captcha-Session"]
    captcha_hash = response.headers["X-Captcha-Hash"]

    # Save the CAPTCHA image.
    with open("captcha.webp", "wb") as file:
        file.write(response.content)

    # Enter the answer.
    answer = input("CAPTCHA answer: ")

    # Verify the answer.
    verification = client.post(
        f"{API}/api/captcha/verify",
        json={
            "session_id": session_id,
            "captcha_hash": captcha_hash,
            "answer": answer
        },
        timeout=15
    )

    verification.raise_for_status()

    print(verification.json())
